# 牛牛 配当計算アプリを Vercel に移す（ログインなし・リンク共有で同時編集）

## ゴール
- URL を知っている人なら、ログインなしで同じ戦績に記録・閲覧できる
- だれかが記録すると、開いている全員の画面に数秒で反映される
- 今の計算・早見表・戦績（グラフ・罫線・履歴・修正・1つ戻す）はそのまま

## 構成（決定: Vercel の保存機能 = Upstash Redis）
- ページ: `public/niuniu/index.html`（静的。`/niuniu` で開けるよう next.config.js に rewrite）
  - URL: `https://<vercelのドメイン>/niuniu?t=<卓ID>`（卓ID なしで開くと自動発行）
- API: `src/app/api/niuniu/[table]/route.ts`
  - `nn:<卓ID>:hands` / `nn:<卓ID>:players`（1手・1人 = 1フィールドなので同時に書いても上書きしない）
  - `nn:<卓ID>:rev` を書き込みごとに +1。各端末は3秒ごと（画面表示中のみ）に rev だけ確認し、変わったときだけ全件取得
  - 入力値はサーバー側で形式チェック
- 早見表・ベット設定は各自の端末（localStorage）
- 保存先が未設定・通信不可のときは端末に記録し、つながったら卓に合流
