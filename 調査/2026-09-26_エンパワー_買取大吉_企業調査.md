## 2. 顧客

顧客は2層ある。

### (1) 一般の売り手（エンドユーザー）
- 主な持ち込み品: 金・プラチナ等の貴金属、ブランド品、ジュエリー、時計、切手、古銭など
- 訴求: 「地域の買取窓口」「気軽に売れる」。スーパー（マミーマート等）の中・近隣への出店が多く、生活動線上の立地
- 顧客層の統計は公開情報なし。CM（IKKO起用・ブランド／ジュエリー訴求）や立地からは主婦層・シニア層が中心と**推測**される（推測）
- 評判:
  - ヒカカク 総合3.84点（口コミ約1,180件）【C】／みん評 口コミ約1,600件【C】
  - 良い声: 「予想以上の価格」「接客が丁寧」「査定・キャンセル無料」
  - 悪い声: **査定品をバックヤードに持って行き目の前で査定しない → すり替え・無断出品への不安**、査定額の店舗差・担当者差、減額交渉の待ち時間、「断りにくい」、出張買取の予約すっぽかし
  - 「査定品を奥に持ち込みオークション出品」疑惑が炎上した報道あり（coki）【C】
- 会社側は強引な取引を禁止する社内規定・手数料無料を説明している【B】

### (2) FC加盟オーナー（本部にとっての顧客）
- 未経験・1人運営モデルを訴求。月額固定ロイヤリティは売上が伸びるほど有利
- 現役オーナーのブログでは「店舗差・立地差で成否が分かれる」との発信あり【C】
- 批判的な「被害者の会」サイトも存在【C】

### (3) 業者（BtoB）
- 「大吉オークション」で買取品を業者向けに流通

## 4. まとめ（所感）
- **会社**: 急成長（3年で売上約2倍、店舗2,000超）のFC型買取チェーン最大手。一方でオーナーシップを巡る報道リスクは未解消で、一次情報での確認が必要。
- **顧客**: 立地の身近さと広告で集客力は高い。評価は中〜やや高評価だが、「目の前で査定しない」ことへの不信感が繰り返し出る構造的な弱点。
- **従業員**: 「高給・未経験可」と引き換えに、異動の多さ・成果プレッシャー・制度変更の多さが不満の中心。長期育成の評価が低い（2.3）。

## 6. 追加調査：営業職の年収（2026-09-27）

### 前提（本人ヒアリング）
- 会社説明：「4人に1人が（初年度）年収1,000万円を達成」
- 初年度オファー：約530万円

### 公開データ
| 項目 | 値 | 出典・信頼度 |
|---|---|---|
| 全体平均 | 585万円（50名回答）／別時点 571万円 | OpenWork【C】 |
| **営業の平均** | **596万円** | OpenWork【C】 |
| スーパーバイザー平均 | 348万円（サンプル少と推測） | OpenWork【C】 |
| 店長平均 | 1,178万円 | 二次記事（OpenWork由来）【C】 |
| 出張買取部の平均 | 1,300万円との回答 | OpenWork Q&A【C】 |
| 営業の個別事例 | 450万円（基本300・残業60・賞与15）／968万円（基本480・残業288・賞与100） | OpenWork【C】 |
| 求人の月収 | 月収50.1万円〜（うち月給30.1万円＋インセンティブ・特別手当） | エン転職【B】 |
| 採用訴求 | 「4人に1人が初年度1,000万円超」「未経験入社95%」 | マイナビ転職（掲載終了）【B】 |

### 解釈
- 「営業以外が平均を押し下げている」仮説は、営業平均596万円≒全体平均585万円のため**データ上は弱い**。
- 高収入は店長・出張買取など一部に集中し、**上位の少数が平均を押し上げる右に長い分布**と考えるのが整合的。
  - 仮に25%が1,100万円なら、残り75%の平均は約410万円で全体585万円になる計算。
- 「4人に1人」は分母（初年度を1年在籍した人のみか／職種・年度）が不明。早期離職者が分母から外れていれば数字は高く見える。
- 口コミの年収は過去の制度・短期在籍者を含むため、現行制度より低く出ている可能性もある。

### 企業に確認すべき点
1. 「4人に1人」の分母（対象職種・年度・在籍1年未満の退職者を含むか）
2. 営業の年収の**中央値**と分布（〜500／500〜800／800〜1,000／1,000〜）
3. オファー530万円の内訳：月給・固定残業代（何時間分）・特別手当（期限付きか）・インセンティブ見込み
4. インセンティブ制度の直近の変更履歴と、変更時の通知ルール
5. 入社1年以内の離職率、異動・転勤の頻度
